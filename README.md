## 第二笔账：带宽按什么标准算，流量超了怎么收

同样是“2核4G”，阿里云经济型 e 从 1M 带宽升到 5M，价格从 599.93 元涨到 1640.33 元，平均每 M 约 260 元一年；通用算力型 u2a 从 1M 的 504.60 元升到 5M 的 810.60 元，平均每 M 只有 76.5 元一年。同一家厂商、同样核数内存，带宽单价差三倍多。

## 第三笔账：轻量还是 ECS/CVM

超低价机型绝大多数是轻量应用服务器，和标准 ECS/CVM 不是一类产品。

轻量是套餐制：CPU、内存、系统盘、月流量、带宽打包成一个价格，控制台简化，一键应用镜像，适合单机应用。代价是流量包有上限、CPU 资源共享、网络隔离受限，不能自定义 VPC、挂负载均衡、做弹性伸缩。同配置下常规 CVM/ECS 价格通常是轻量的 2 到 3 倍，腾讯云轻量 2核2G 68 元，CVM 标准型 S5 2核2G 1M 是 261 元，差距就在这儿。

阿里云经济型 e 虽然属于 ECS 体系，但采用共享调度，性能存在一定波动，官方定位就是成本优先的轻量业务。真要稳定算力，得往 u2a、c9i 这些规格族走。

什么业务不该买轻量：要接 RDS、OSS、Redis 等多个云产品的；要做多机负载均衡和高可用架构的；CPU 长期跑满的计算型业务；对网络有精细安全组要求的企业内网。这些场景硬上轻量，一两年内大概率要迁移一次，迁移成本远高于当初省下的钱。
